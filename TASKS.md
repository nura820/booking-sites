# Очередь задач

Ночная задача берёт ОДНУ верхнюю незакрытую задачу, делает её в отдельной ветке и открывает запрос на слияние. Выполненное отмечается `[x]` в том же запросе.

## В очереди
- [ ] 1. Заявка владельцу в WhatsApp. После подтверждения записи открывать ссылку `https://wa.me/<номер>?text=<текст заявки>` с именем, телефоном, услугами, мастером, датой и временем. Номер владельца вынести в настройку сферы (`NICHES[*].ownerWhatsapp`). Кнопка «Отправить заявку в WhatsApp» на экране подтверждения; без номера кнопки нет.
- [ ] 2. Выкладка на бесплатный хостинг GitHub Pages: проверить, что сайт работает из корня репозитория по относительным путям, добавить в README инструкцию включения Pages. Сам Pages включает владелец репозитория.
- [ ] 3. Режим одной сферы для клиента: параметр в начале скрипта (`ONLY = 'barber'`), при котором вкладки сфер скрыты и сайт выглядит как сайт одного бизнеса.
- [ ] 4. Вынести данные клиента (название, адреса, телефон, часы, соцсети, прайс) в один блок в начале файла с комментариями на русском, чтобы настройка под клиента занимала 15 минут.
- [ ] 5. Убрать пометки «демо» и вымышленные отзывы в режиме одной сферы, если клиент не дал свои отзывы (блок отзывов скрывать).
- [ ] 6. Проверка на телефоне 360–390px: шапка, выбор времени, нижняя панель. Исправить найденное.
