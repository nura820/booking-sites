# booking-sites

Шаблон сайта с онлайн-записью и предзаказом для малого бизнеса в Астане. Один файл `index.html`, три сферы: автосервис, кофейня, барбершоп.

## Как посмотреть
Откройте `index.html` в браузере. Интернет нужен для шрифтов, библиотек (GSAP, ScrollTrigger, Lenis) и запасных фото.

## Медиа
Свои фото и видео кладутся в `assets/`, имена файлов перечислены в `assets/README.txt`. Пока файла нет, показывается запасное фото.

## Что важно знать
- Это демо: заявка никуда не отправляется, адреса, телефоны, отзывы и рейтинги вымышлены.
- Вся разница между сферами задаётся объектом `NICHES` в `index.html`.
- Очередь задач лежит в `TASKS.md`. Правила работы для Claude — в `CLAUDE.md`.
