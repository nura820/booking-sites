# Правила работы в этом репозитории

- Сайт — один файл `index.html` (HTML, CSS в `<style>`, JS в `<script>`). Сборки нет. Библиотеки только GSAP, ScrollTrigger и Lenis с CDN, новых не добавлять.
- Язык интерфейса и комментариев — русский. Цены в тенге.
- Никакой графики, нарисованной кодом (canvas, 3D, декоративный SVG). Только фото и видео из `assets/` с запасными ссылками. Существующие пути `assets/...` и запасные ссылки не менять.
- Анимации появления 0,4–0,5 с. Содержимое должно быть видно без JS-библиотек и при `prefers-reduced-motion`.
- Оплата: наличными на месте и Kaspi как необязательный вариант. Оплаты картой онлайн нет. Данные карт не собирать.
- Сайт не должен отправлять данные посетителей никуда, кроме явного действия пользователя (например, открытие WhatsApp с готовым текстом).
- Не трогать крючки вёрстки: `data-tab`, `.tile`, `data-svc`, `#bnext`, `.slot`, `#fn`, `#fp`, `.okb`.
- Никогда не пушить в `main`. Каждая задача — отдельная ветка `task/<номер>-<кратко>` и запрос на слияние с описанием на русском: что сделано, как проверить, что не проверено.
- Одна задача из `TASKS.md` за один запуск. Если задача неясна или требует решения владельца, не угадывать: открыть issue с вопросом и остановиться.
- Перед запросом на слияние: проверить синтаксис скрипта (`node --check` на извлечённом скрипте) и отсутствие горизонтальной прокрутки на 390px, если доступен браузер.
