# Правила работы в этом репозитории

- Сайт — один файл `index.html` (HTML, CSS в `<style>`, JS в `<script>`). Сборки нет. Библиотеки только GSAP, ScrollTrigger и Lenis; их файлы лежат в `assets/vendor/` (скачивает `.github/workflows/fetch-assets.yml`), новых не добавлять. Шрифты лежат в `assets/fonts/`. Сайт не должен грузить ничего с чужих серверов, кроме запасных ссылок на фото.
- Язык интерфейса и комментариев — русский. Цены в тенге.
- Никакой графики, нарисованной кодом (canvas, 3D, декоративный SVG). Только фото и видео из `assets/` с запасными ссылками. Существующие пути `assets/...` и запасные ссылки не менять.
- Анимации появления 0,4–0,5 с. Содержимое должно быть видно без JS-библиотек и при `prefers-reduced-motion`.
- Оплата: наличными на месте и Kaspi как необязательный вариант. Оплаты картой онлайн нет. Данные карт не собирать.
- Сайт не должен отправлять данные посетителей никуда, кроме явного действия пользователя (например, открытие WhatsApp с готовым текстом).
- Не трогать крючки вёрстки: `data-tab`, `.tile`, `data-svc`, `#bnext`, `.slot`, `#fn`, `#fp`, `.okb`.
- Каждая задача — отдельная ветка `task/<номер>-<кратко>`. Владелец разрешил (05.10.2026) вливать ветку в `main` самостоятельно, без запроса на слияние, но только после того, как прошли все проверки из последнего пункта. Вливать обычным слиянием (`git merge --no-ff`), без `--force` и без переписывания истории `main`. Сайт публикуется из `main`, поэтому в сообщении слияния и в отчёте писать: что сделано, как проверить, что не проверено. Если проверки не прошли, в `main` ничего не вливать: оставить ветку и открыть issue.
- Одна задача из `TASKS.md` за один запуск. Если задача неясна или требует решения владельца, не угадывать: открыть issue с вопросом и остановиться.
- Перед слиянием в `main`: проверить синтаксис скрипта (`node --check` на извлечённом скрипте) и отсутствие горизонтальной прокрутки на 390px, если доступен браузер.
